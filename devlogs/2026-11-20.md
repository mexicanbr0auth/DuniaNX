# DuniaNX — Development Log

Date: November 20, 2026

## Milestone: Android Developer Preview v0.6

Native startup and a restricted Vulkan backend now run inside
a signed Android diagnostic application, outside Termux.

| Metric | Preview v0.5 | Preview v0.6 |
|:---|---:|---:|
| Runtime imports | 2,524,333 | 2,525,075 |
| Offscreen draws | 4 | 5 |
| EDRAM resolves | 2 | 4 |
| Completed rings | 13 | 15 |
| GPU packets | 609 | 948 |
| Shader loads | 12 | 20 |
| Presented frames | 0 | 0 |

Device: Mali-G57 MC2, Vulkan 1.3.303, ARM64 Android.

The original BC1 texture diagnostic decoded a 128 × 128 texture,
uploaded the RGBA pixels to Vulkan and verified all 65,536 bytes
on readback. This is a diagnostic asset operation, not a rendered
frame from the game engine.

## Graphics progress

The runtime supports a restricted set of original rectangle
draws and homogeneous EDRAM tile contents. Color, depth and
stencil effects have been verified through offscreen Vulkan
operations. The resolve path transfers supported uniform data
into guest tiled memory, including both halves of a 1280 × 696
texture. It is not a general Vulkan resolve implementation.

Native boot 193 completed 15 rings, five offscreen draws and
four resolves, reaching 2,544,008 runtime import calls. Preview
v0.6 reproduced the same functional milestone on Android.

## Verification

- 4,963,744 graphics integration assertions passed in the latest
  targeted test run (including pixel and tiled memory checks).
- 1,556 PM4 frontend checks and 47 lifecycle checks passed in the
  relevant earlier targeted regression run.
- 32,780 raster geometry checks and an independent comparison
  of 901,120 tiled addresses passed.
- APK signature v3 verified; the application was tested on device.

The complete regression suite has not been rerun after the latest
graphics changes. Import calls and shader loads are execution counts,
not unique functions or translated shaders.

## Next milestone

Startup currently stops at `VdGetSystemCommandBuffer`.
The next work is system command buffer compatibility, `VdSwap`,
frontbuffer handling and real image presentation.

No complete game frame, main menu or gameplay has been demonstrated.
The preview is private. No proprietary game files, assets, generated
game code or APK binaries are included in this public repository.
